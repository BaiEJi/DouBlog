# 书签与稍后阅读模块 UI 验收（2026-10-16）

新增 bookmarks 模块（`/bookmarks`，五视图 + 详情/表单/分类管理覆盖层 + 门户卡）的首次可视化验收，由 image 子智能体对 14 张实拍截图逐张走查（基线 `docs/ui-baseline.md` v1 + 模块 orange 个性色约定），FAIL 项修复后复审通过。

## 验收环境与方法

- 独立 QA 实例：后端 60110（**SQLite**，`data/db_config.json` 固定，不碰共享 PG）+ vite 60111 同源代理（`VITE_API_PROXY`）；演示数据 14 条书签（多状态/星标/死链标记/离线快照 2 篇）+ 5 分类 + 12 标签
- Edge headless（playwright-core）实拍，桌面 1440×900；外网 favicon 不可达属离线环境预期（字母块回退即正确表现）
- 截图存 `docs/shots11/`（01-14）

## 覆盖页面

收藏夹列表（明/暗/批量操作条三态）、稍后阅读队列（英雄卡+队列）、统计（明/暗：指标卡/状态环形/30 天趋势/分类·标签·站点 TOP）、工具（导入导出/死链检测/重复链接）、回收站、详情页含快照 Markdown 渲染（明/暗）、编辑/收录表单、分类管理模态、门户新书签卡。

## 审查结论与修复

首轮：10/14 PASS；4 张 FAIL（3 项 P2 + 若干 P3），全部修复：

| 问题（首轮发现） | 严重度 | 修复 |
|---|---|---|
| favicon 字母块回退不稳（无图标站点渲染成空白方框，选中高亮/暗色下明显） | P2 | `Favicon` 改为字母块常驻底层 + img 成功加载才覆盖（onError 与 naturalWidth=0 都触发移除）——任何情况下不再出现空白框 |
| 星标指示悬浮在右上角与操作列星标按钮斜向叠邻，读作渲染重复 | P2 | 移除悬浮星标，改为标题旁琥珀色小徽章（`bg-amber-500/10` 底） |
| 队列英雄卡整片橙色渐变底纹超出"orange 仅用于图标底/徽章/主按钮/选中态"约定 | P2 | 收敛为标准中性卡片，橙色仅保留 eyebrow 圆点+文字与主按钮；文案改"下一篇待读" |
| 筛选区三个下拉全宽堆叠（`inputCls` 的 `w-full` 与 `w-44` 类冲突） | P3 | 改显式 `style={{width}}`（分类 11rem/标签 9.5rem/排序 8.5rem/批量移动 9rem/分类管理父级 10rem） |
| 复选框暗色下纯白实底 | P3 | 行复选框与全选框补 `dark:[color-scheme:dark]` |
| 回收站 H1 与区块标题文案重复 | P3 | 区块标题改"已删除条目" |

复审（4 张重拍）：02/04 PASS；发现 01/03 新 P2——亮色模式下字母块被 img 元素自身的不透明 `bg-white` 背景盖住（外网 favicon 请求超时期间 img 尚未触发 onError，暗色变体是半透明所以字母可见）。修复：img 移除全部背景色（透明），字母块为唯一底色——请求慢/失败期间字母透出，成功加载的 favicon 自然覆盖。重拍 3 张后终审通过（01/03/04 全 PASS，无遗留必修项）。终审附一条 P3 建议：字母块底色跨页观感不一（实为同一 Favicon 组件、同为 orange-500/10，截图压缩下的观感差异，已核实一致）。

修复过程中另确认的生效项：筛选下拉显式宽度横排、星标徽章移至标题旁（不再叠邻）、复选框暗色描边、英雄卡中性化 + eyebrow 文案"下一篇待读"。
