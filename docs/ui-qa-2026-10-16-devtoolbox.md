# 开发者工具箱 UI 验收记录（2026-10-16，feat/devtoolbox 分支）

> 验收方式：隔离环境（后端 60113 独立 SQLite + 前端 60115 同源代理，不触碰主服务 60100/60101），
> 47 张截图（33 亮 + 14 暗，1440 视口）经 image 子智能体审查 + DOM 断言复核。

## 审查结论

- **23 pass / 24 fail**（首轮）——fail 项经溯源全部分类为三类：①截图采集管线缺陷（IAB fullPage 平铺伪影、
  表面缓存冻结、MSYS 路径转换破坏 `VITE_API_BASE` 致接口打向 60100 被 CORS 拦）②两处真实前端 bug ③采集期后端进程被外部终止
- **修复后复核：速查表修复确认 pass**（分区只含本区状态码）；其余 P0/P1 确认为采集流程问题而非 UI 缺陷

## 审查发现并已修复的真实问题

| 级别 | 问题 | 修复 |
|---|---|---|
| P1 | 速查表 HTTP 状态码分组过滤条件错误（`c<300` 把 1xx 混入 2xx，各分区累积重复） | data.js 分组改为区间判断 `c>=200&&c<300`；DOM 断言 1xx-5xx 各分区首码 100/200/301/400/500 |
| P2 | 后端不可达时错误文案为英文原文 Failed to fetch | api.js 捕获 TypeError 转中文提示（保留 cause） |
| P1 | ToolHead 未实现 `right` prop，各工具头部控件（方向切换/选项/按钮）被静默丢弃 | kit.jsx ToolHead 支持 right（children 兼容别名），逐工具复验控件渲染 |

## 环境坑位记录（复验时注意）

- **Git Bash 启动 vite 传 `VITE_API_BASE=/` 会被 MSYS 路径转换改写**（症状：页面可开但所有接口
  Failed to fetch——前端回退硬编码 60100 被 CORS 拦）；启动命令须加 `MSYS_NO_PATHCONV=1`
- IAB fullPage 截图在高分视口下出现 2×2 平铺伪影；连续大量截图后表面缓存冻结（新建标签页可短暂恢复）——
  完整像素矩阵复验建议改用独立无头浏览器
- 隔离后端用 `Start-Process` 分离启动更稳（普通后台任务约 10-25 分钟后被宿主终止，无错误栈）
